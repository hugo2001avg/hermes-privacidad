Política de privacidad de Hermes

Vigente desde el 20 de noviembre de 2026.

Quién la usa

Hermes es una aplicación de uso personal. La única cuenta que la autoriza es la de su dueño, y nadie más tiene acceso a ella.

Qué datos de Google usa

  • Gmail (lectura): lee los correos para resumirlos o buscar algo cuando el dueño lo pide.
  • Gmail (borradores): prepara borradores. Nunca envía un correo sin que el dueño lo apruebe.
  • Google Calendar: consulta la agenda y crea o cambia eventos cuando el dueño lo pide.

Cómo se tratan

  • Los datos se usan solo para responderle al dueño. No se venden, no se usan para publicidad y no se comparten con nadie.
  • Para armar cada respuesta, el texto necesario se manda a un proveedor de modelos de lenguaje (DeepSeek) por su API. El proveedor lo procesa y no se le pide que lo guarde.
  • Las credenciales y el historial del chat se guardan en un servidor privado del dueño.
  • El uso de la información recibida de las API de Google sigue la Política de datos del usuario de los servicios de las API de Google, incluidos sus requisitos de uso limitado.

Cómo revocar el acceso

El acceso se quita en cualquier momento desde myaccount.google.com/permissions.

Contacto

Escribe al correo de asistencia que aparece en la pantalla de autorización de Google.
